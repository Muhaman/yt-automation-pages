# Privacy Policy - Shorts Youtube

Last updated: 12 November 2026

Shorts Youtube ("the app") is a personal tool used only by the owner of the Little Muslim Stories YouTube channel to upload videos to that channel.

## What the app accesses

The app requests one Google permission, `https://www.googleapis.com/auth/youtube.upload`, which lets it upload videos to the signed-in YouTube channel. It does not read email, contacts, files, or viewing history.

## How data is stored and used

The access token Google issues is stored only on the owner's own computer and is used only to upload videos to the owner's channel. No user data is sent to any server run by the app, and no data is sold, shared with third parties, or used for advertising.

## YouTube API Services

The app uses YouTube API Services. Use of the app is subject to the YouTube Terms of Service (<https://www.youtube.com/t/terms>). Data handled by Google is covered by the Google Privacy Policy (<https://policies.google.com/privacy>).

## Revoking access

Access can be removed at any time at <https://myaccount.google.com/permissions>. Deleting the stored token from the computer also ends all access.
