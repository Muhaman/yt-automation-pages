# Shorts Youtube

Shorts Youtube is a personal automation tool run by the owner of the **Little Muslim Stories** YouTube channel: <https://www.youtube.com/@muhamanahmed2928>

It renders short animated videos on the owner's own computer and uploads them to that one channel using the YouTube Data API. It is not offered to the public and has no other users.
